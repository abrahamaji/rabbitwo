# Professional Website Starter

Built with:
- HTML
- CSS
- JavaScript

## Open in VS Code

1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
4. For a better development experience, install the VS Code extension **Live Server** and use **Open with Live Server**.

## Project structure

```text
professional-website-starter/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## GitHub

From the project folder:

```bash
git init
git add .
git commit -m "Initial website"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```
